B-TECH-DRC SA — VERSION GRATUITE GITHUB PAGES

1. Créez un compte sur GitHub.
2. Créez un repository, par exemple btech-drc-site.
3. Téléversez index.html et le dossier assets.
4. Settings > Pages > Deploy from a branch > main > /root > Save.
5. GitHub fournira votre adresse gratuite.

Cette version est statique : elle ne nécessite aucun hébergement payant ni PHP.
Le contenu peut être modifié directement dans index.html.
